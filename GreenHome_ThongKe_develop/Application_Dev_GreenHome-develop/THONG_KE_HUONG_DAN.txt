GREENHOME - TICH HOP THONG KE SQL SERVER

Cac file da them/cap nhat:
- src/ui/ThongKePanel.java: giao dien 4 tab, bo loc ngay, bieu do va bang.
- src/bus/ThongKeBUS.java: kiem tra khoang ngay va dieu phoi truy van.
- src/dao/ThongKeDAO.java: truy van SQL Server cho hoa don, san pham, khach hang va doi tra.

CAI DAT
1. Giai nen project va mo/import project vao Eclipse.
2. Dam bao SQL Server da chay va database GreenHome da duoc tao bang script:
   database/01_TaoDatabaseGreenHome.sql
3. Copy config/db.properties.example thanh config/db.properties.
4. Sua url, user, password trong config/db.properties cho dung SQL Server tren may.
   Khong commit file db.properties co mat khau len Git.
5. Kiem tra Microsoft JDBC JAR trong lib/ da duoc Add to Build Path.
6. Chay ung dung GreenHome va mo chuc nang Bao cao & thong ke.

QUY TAC TINH
- Hoa don: chi lay hoa don co DON_HANG.trangThaiDH = N'DaThanhToan'.
- Tien dong hang: giaChuaThue + tienVAT - soTienGiam.
- Doanh thu thuan: tong ban hang tru tien hoan cua phieu co trangThaiDuyet = HoanTat.
- Tien hoan: lay tu CHI_TIET_PHIEU_DOI_TRA.thanhTienHoan; gia tri NULL duoc tinh la 0,
  khong tu uoc tinh tien hoan.
- Tab san pham thong ke so luong va doanh thu theo ten san pham.
- Tab khach hang phan biet khach thanh vien theo maKH va khach vang lai theo hoa don.
- Tab doi tra dem 4 trang thai ChoDuyet, DaDuyet, TuChoi, HoanTat.

LUU Y
- ThongKePanel hien tai doc du lieu dong bo khi tai/loc; voi database rat lon co the mat vai giay.
- Cac bang trong file SQL goc la schema chinh. Neu project cua nhom da dung schema khac,
  can doi chieu ten cot truoc khi chay.
- Da kiem tra bien dich Java cua source sau khi tich hop; chua the kiem thu truy van tren
  SQL Server thuc te vi can thong tin ket noi va du lieu tren may cua ban.
